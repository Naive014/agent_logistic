# Проверка входящего ТЗ

Перед первой отправкой запроса агент проверяет 21 обязательный заголовок
из предоставленного образца «Пример ТЗ.xlsx», лист «Матрица ТЗ_РФ», A1:U1.
Полный список хранится в `template_excel.REQUIRED_TENDER_HEADERS`.
Эталонный файл не требуется на компьютере при запуске сервиса.

Используется лист `EXCEL_SHEET` либо активный лист и строка `EXCEL_HEADER_ROW`.
Порядок столбцов свободный, дополнительные столбцы допускаются.
Регистр, начальные/конечные и повторяющиеся пробельные символы игнорируются.
Для пункта отгрузки и региона сохранены ранее поддерживаемые альтернативные
названия. Отсутствующие или повторяющиеся обязательные столбцы перечисляются
в ошибке. Прочие изменения текста заголовков не нормализуются.

Это проверка структуры, а не заполненности всех полей: обязательными значениями
остаются пункт отгрузки и регион доставки. Строки без обоих значений пропускаются,
неполные направления и формулы в этих двух полях отклоняются. Требуется хотя бы
одно направление. Остальные поля могут быть пустыми.

Проверяется также ранее сохранённый запрос, если его отправка ещё не начиналась.
Уже отправленные запросы и восстановление подтверждённой отправки не блокируются
новыми требованиями. Обработка ответов к старым запросам остаётся совместимой.

При ошибке запрос не отправляется, исходное письмо не помечается прочитанным,
причина записывается в `workdir/logs/request-agent.log`. Автоматическое уведомление
пользователя об ошибке не реализовано; агент повторит проверку в следующем цикле.
После обновления кода необходимо перезапустить работающие агенты.
